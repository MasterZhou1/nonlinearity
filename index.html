Anything that can improve itself stops being linear.

Recursive self-improvement is not only a story about AI agents improving AI agents. Anything that lives in computer and language space — code, proofs, experiments, entire fields of science — can now read its own output and act on it. That feedback is what bends a straight line into a curve.

scope / 02

Where the term switches on.

01 / science

Experiments that design the next experiment

A result stops being an endpoint and becomes an input. The loop from question to evidence can close without waiting for a person to read the log.

02 / models & agents

Systems that rewrite their own tooling

Models and agents that improve the thing producing them. Each pass changes not only the artifact but the capability that made it.

03 / language

Anything expressible becomes improvable

Proofs, specifications, plans, arguments. If it can be written down, it can be evaluated and revised by the same process that wrote it.

about / 03

What we are building.

Nonlinearity is an early-stage AI company. We build systems that run the loop end to end — proposing, executing and evaluating their own work — and the infrastructure that makes those loops cheap enough to leave running. Our bet is that the self-influence term is already switching on, unevenly, across everything that can be represented as text. We are prototyping, not selling yet.
